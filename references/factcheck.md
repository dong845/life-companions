# Fact-check gate — the required artifact for high-stakes external facts

This is the *hard* version of `safety.md §1 rule 6`. Rule 6 says "verify, don't
assume." This file makes it **checkable**: a high-stakes factual/eligibility answer
does not ship without the block below attached. If you can't fill the block, you
haven't done the work yet — go do it, or say you couldn't.

**When this gate is mandatory** (same trigger as rule 6 — shape, not domain word):
the person will *act* on an external, changeable fact and being wrong costs real
money, time, legal standing, or a major life move — eligibility (visa, PR, tax,
benefit, grant, scholarship, licensing), a threshold/number/deadline, or a specific
employer's/program's/market's current status.

## The required block (attach it; don't bury it)

Render it in the person's language; keep it tight. Every load-bearing fact gets a row.

```
── 事实核查 ─────────────────────────────
· <claim / 结论>
    来源: <official/primary source> · 时效: as of <YYYY-MM>（可能已变）
    状态: ✅已核 / ⚠️业内解读待官方确认 / ❓未能核实
· <number / threshold / deadline>
    来源: <source> · 时效: as of <YYYY-MM>
    状态: …
你需要自己确认: <the person-specific facts only they know, and the binding checks>
  — e.g. 你的确切居留起始日 / 博士居留类型 / 拿你的证件去 IND 或律师核
─────────────────────────────────────
```

Rules for the block:
- **No number without a dated source.** A threshold, salary line, fee, or deadline
  stated with no `来源 + 时效` is a bug — quote it from the fetched source or write
  "以官方现行为准". (rule 6d)
- **Mark honestly:** ✅ only for something you fetched from a live official/primary
  source; ⚠️ for a widely-held interpretation the official page doesn't state
  verbatim (say whose interpretation); ❓ for anything you couldn't confirm — and
  then **do not assert it as fact** (rule 6f).
- **"你需要自己确认" is not optional.** Name the person-specific facts you had to
  assume or ask for, and the binding check (official authority / licensed
  professional per rule 5). If a deciding fact was unknown, you should have **asked**
  (rule 6b) before concluding — the block records what still needs confirming.

## Pre-send self-audit (run before you deliver)
- Did I actually research a live source, or answer from memory? (memory → stop)
- Did I have web access at all? If not I cannot fill this block — say so and route to
  the source, rather than reconstructing it from recall.
- Is every threshold/deadline carrying a dated source?
- Did I test the rule's conditions against *this* person, and ask the deciding fact
  rather than defaulting yes/no?
- Did I enumerate the real options (incl. ones they've already accrued, like PR)?
- Did I flag eligible-≠-worth-it and any irreversible tradeoff?
- Is the block present and honestly marked? If any row is ❓, did I avoid asserting it?

This gate is for **external checkable facts only** — never apply it to the reflective
lenses (BaZi / career-fit / attachment / a daily reading), which are labeled
reflections, not claims. (safety.md §1 rule 6, final clause.)
