> **一个用真实历法和真实星历给你排盘、记得你上周说过什么，却绝不编评分、不编幸运数字、也不给你们的感情下判决的陪伴。**

算命类 App 很乐意给你今天打四颗星，再附送一个幸运数字。life-companion 要避开的正是这种答案，所以它把两件事分开做。**计算**全部交给脚本，从不让模型心算：八字四柱按真实节气交接，西洋本命盘用瑞士星历，还有紫微斗数，职业匹配对照 188 个真实的 O\*NET 职业。**解读**明确标成一面镜子，是看盘面或数据的一种角度，不是预言。回复发出去之前，一道写进代码的诚实闸门会拦下几种已知的「滑回算命腔」的写法。

它是给 [Claude Code](https://claude.ai/code) 和 [Codex](https://openai.com/codex) 用的 skill，任何能跑 Python、能读文件的 agent 也都能用。你跟它说话就行。它在你自己机器上的 `~/.companion/` 里存一份档案和日记，存敏感内容之前先问你，还会跟进你说过要做的事。所有计算都不联网。

<a id="从这里开始"></a>

## 从这里开始

你不用挑模块。说出你在想的事，对应的角度自己就来了：

| 你想要 | 角度 | 你会拿到 |
| --- | --- | --- |
| 看命盘 | **命理命盘**：八字 · 西洋星盘 · 紫微斗数 · 合婚 | 先是算出来的盘，再是大白话解读，从一句话画像一直展开到分阶段的人生时间轴 |
| 看看今天，或者记下今天 | **每日运势 + 日记** | 一张简短的当日卡片，和你日记里真实写下的东西织在一起；需要的话顺手把今天记下来 |
| 想清楚工作方向 | **工作匹配** | 21 题兴趣小测，对照 188 个真实 O\*NET 职业，给低／中／高档位，不给百分比 |
| 理清一段关系 | **恋爱反思** | 把「实际发生了什么」和「脑补的故事」分开，两边都站；记录里真有模式才叫模式；再给一个具体的下一步 |
| 就是想聊聊 | **日记 + 记忆** | 一个记得你最近几周的人，温和地跟进一件事 |

[装好之后](#安装)，说话大概是这样：

```text
用 life-companion —— 帮我看看八字，1993-04-12 早上 7:35，男，北京出生。
用 life-companion —— 今天运势怎么样？顺便记一下：今天有点丧，心情 4/10。
用 life-companion —— 我不确定自己适合做什么工作。
用 life-companion —— 昨晚跟对象吵架了，帮我理一理。
```

它先回答你问的事。哪个模块都不需要先建档才能算，所以关于你的问题放在回答之后，给你一小组选项点选。

<a id="你会拿到什么"></a>

## 你会拿到什么

两种输出，分得清清楚楚：

| | 是什么 | 从哪来 |
| --- | --- | --- |
| **算出来的** | 四柱、大运、行星位置、紫微宫位、职业契合档位、情绪走势 | 脚本算的：可复现、不联网。模型从不手算命盘 |
| **读出来的** | 这些对你可能意味着什么 | 标明了是镜子：一种看法，不是预言 |

**解读里有什么。** 先摆算出来的事实，再用大白话解读，术语第一次出现就带夹注。免责声明只在开头说一次，后面就好好说话，不在每句里都塞「可能」。几套体系说法不一致的时候，比如今天的八字偏一边、生肖关系偏另一边，它会直接说出来，不会揉成一个总判断。

**解读里没有什么。** 没有星级评分，也没有编出来的幸运数字：颜色和数字只作为你八字喜用五行的传统对应出现，并且标明是这个。工作匹配不给百分比。合婚不给「合／不合」的结论、分数或建议。不说「你会……」，不预言疾病、分手或破产，也不给医疗、财务、法律建议。遇到危机，就完全不看盘，直接给真实的本地求助渠道。

**什么留在你机器上。** 档案、同意记录、每月一个 Markdown 文件的日记，以及存命盘缓存和跟进线索的小文件夹，都在 `~/.companion/` 里。这个文件夹在 skill 自己的目录之外，安装和更新都不会碰到它。[详见下文](#你的数据与隐私)。

## 它和别的不一样在哪

能给你算命的工具很多。区别在于那些说法后来怎么样了：

- 🧮 **脚本算，从不手算** —— 八字按真实节气交接，测试里逐柱对照一套独立历法；西洋星盘走瑞士星历；职业数据从 O\*NET 31.0 数据库重建。不知道出生时间，就不给上升点、不起紫微盘，不去猜一个。
- 🪞 **是镜子，不是预言** —— 每段解读都标明是一种看法。它不说会发生什么；真要定工作、定感情、定钱的时候，它把问题交给真正管这件事的模块，不让一段解读替你拍板。
- 🚦 **诚实规则写进代码，不靠自觉** —— 回复发出去之前，一道闸门会拦下数字或文字里编出来的精确度、宿命论（包括「大概率保不住」这种对冲过的）、给不在场的人贴临床标签，以及编造的求助热线号码。
- 🧠 **记得你，也会跟进** —— 档案、日记和你没做完的事跨会话保留；它会温和地跟进一件你打算做的事，不唠叨。
- 🔒 **本地的，也是你的** —— 生辰、感情记录、情绪各自单独授权，没授权的写入在代码里直接拒绝。`forget` 先列出要删什么，再把每一份副本都删掉。
- 🆘 **危机面前收起算命** —— 不看盘，也不说「星象说会过去的」：按你所在的地方给真实的求助热线，不知道你在哪就给 findahelpline.com，绝不猜号码。

其中三条，来自测试和真实运行里抓到的问题：

**读错了钟的命盘。** 出生地不在北京时间的人，要用两个钟读盘：年柱、月柱看节气交接的那个时刻，日柱、时柱看当地时间。早先的版本只换了显示出来的那几柱，由它们推出来的东西还在读另一张盘。一个在阿姆斯特丹立春刚过出生的人，拿到的生肖是错的，大运方向也反了；抽样 96 个出生时刻，年柱月柱的十神在阿姆斯特丹错了 26 个，纽约错了 50 个，悉尼错了 10 个。现在所有派生项都从页面上显示的四柱推出，测试也在六个时区上逐柱对照一套独立历法。

**用繁体字就溜过闸门的句子。** 诚实闸门里的每一条规则原本都用简体写。「你命中註定會離婚」能通过，它的简体版本却会被拦；「我想自殺」连危机标记都没触发。现在文字会先逐字转成简体再过两道检查，粤语的说法也有了自己的规则。

**当场就删掉的记录。** 在一次 Codex 运行里，「把关于小李的记录都删掉吧」被立刻执行了，尽管文档要求先确认。这条规则只写在一个参考文件里，agent 就跳过了。所以检查搬进了命令本身：现在每次 `forget` 都会先在你数据的副本上真跑一遍删除，列出会删掉什么，等加上 `--yes` 再运行一次才真的删。

## 它会问你什么

只问你这件事需要的，而且放在回答之后：

1. **怎么称呼你、用什么语言、你在哪、喜欢什么语气** —— 第一次回答之后给一次选项。你在哪决定每日时辰，也决定万一需要时给你哪个国家的求助热线。
2. **出生信息，只在看命盘或每日运势时才要** —— 先问要不要存：*存到本机* · *这次算一下，不存* · *不提供*。然后是日期（公历或农历都行，农历由脚本换算，从不手算）、时间（准确、大概或不知道）、出生地，以及大运往哪个方向起：这是传统规则算盘需要的一个设置，不是在说你是谁。
3. **21 道兴趣小题，外加可选的价值观排序** —— 只在你问工作的时候。
4. **记录感情内容的同意** —— 只在你主动聊到一段关系的时候。

它更喜欢让你点选项，而不是打字回答；手边有浏览器时，也可以改用一个本地表单来填。

**它凭现有信息能走到哪一步。**

| 它知道 | 它会给 |
| --- | --- |
| 出生日期 | 没有时柱的命盘；不起紫微盘、不给上升点，不去猜 |
| ……再加大概的出生时间 | 命盘，外加这份不确定可能挪动哪几柱 |
| ……再加准确时间和出生地 | 完整四柱，可选真太阳时，紫微盘和上升点 |

## 快速开始

### 安装

需要 **Python 3.9+**。没有需要手动装的东西：首次使用时脚本会自动获取 `PyYAML`、`lunar-python`、`pyswisseph`、`sxtwl`，装不上时（没网络，或者是 PEP 668 那种系统 Python）会打印确切的安装命令。四条路任选其一。

**方式一 —— 用 [`npx skills`](https://github.com/vercel-labs/skills) 一行装完**（最省事）：

```bash
npx skills add dong845/life-companions
```

它会询问 agent 与安装范围。加 `-g` 全局安装，加 `-a claude-code`（或 `-a codex`）跳过 agent 选择，加 `-y` 全程非交互。仓库根目录本身**就是**这个 skill，所以整个目录会被复制进你的 skills 文件夹。

**方式二 —— 作为 Claude Code 插件安装**（可管理更新）：

```text
/plugin marketplace add dong845/life-companions
/plugin install life-companion@life-companion
/reload-plugins
```

插件里的 skill 带命名空间，调用形式是 `/life-companion:life-companion`。如果你**同时**在 `~/.claude/skills/` 里留着手动装的副本，这个 skill 会出现两次，系统不去重，请删掉一份。第三方 marketplace 默认不自动更新：有新版本时先跑 `claude plugin marketplace update life-companion`，再跑 `claude plugin update life-companion@life-companion`，然后重启。

**方式三 —— 直接克隆**（打算改它就选这个：改完立即生效，插件缓存做不到这一点）：

```bash
git clone --depth 1 https://github.com/dong845/life-companions.git ~/.claude/skills/life-companion
```

**方式四 —— 从 [ClawHub](https://clawhub.ai/dong845/skills/life-companion) 安装**（[OpenClaw](https://clawhub.ai) 智能体的 skill 市场）：

```bash
openclaw skills install @dong845/life-companion
```

life-companion 同时上架了 **[SkillHub](https://skillhub.cn/skills/user_f486c577/life-companion)**（面向中文用户的 skills 社区），适合在那里浏览和横向比较；安装仍然走上面四条路之一。

无论走哪条路，你的数据都不会跟着走：档案和日记在 `~/.companion/`，安装和更新都不会碰到。想确认装好了，在 skill 目录里运行 `python3 scripts/companion.py doctor`。

### 开始用

像聊天一样说话就行。说一句「帮我看看八字」或「今天运势如何」就够触发；在 Claude Code 里也可以敲 `/life-companion`。

建档或做 21 题职业小测时，它可能会提议用本地表单代替聊天：

```bash
python3 scripts/form_server.py --form onboarding    # 或者：--form career
```

它会打印一个 `http://127.0.0.1:<端口>/?token=…` 链接并自动打开。页面只认它打印出来的这条链接，只保存一次提交，提交后或者 15 分钟没人提交就自行关闭。聊天建档是完全同等的方式，不用表单也完全可以。

<a id="你的数据与隐私"></a>

## 你的数据与隐私

```
~/.companion/          chmod 700：在 macOS 和 Linux 上只有你能读
├── profile.yaml       档案
├── consent.yaml       同意记录
├── journal/           日记：每月一个 Markdown 文件，外加 index.jsonl
└── state/             命盘缓存、工作记忆、按人追踪
```

**同意分类授权，随时可撤。** 生辰、感情、情绪各自单独授权。没授权就不收集、不推断、不存储，没授权的写入在代码里直接拒绝。撤回同意和删除是两件事：说「别再用我的生辰」，所有脚本马上停止读取这一类数据，但文件先留着，并且告诉你还留着什么、用哪条命令删，误撤回不会丢东西。

**删除会删到每一份副本。** 对它说就行。删的不只是那一个文件：日记、索引、关系记录、工作记忆、缓存里对应的内容会一起清掉：

| 你说 | 实际执行 |
| --- | --- |
| 「删掉我的生辰数据」 | `companion.py forget --birth` |
| 「忘掉六月」 | `companion.py forget --month 2026-06` |
| 「把刚才那条删了」 | `companion.py forget --entry 2026-06-18 --nth 2` |
| 「关于他的都删了」 | `companion.py forget --person 小李 --with-entries` |
| 「不要再记感情的事」 | `companion.py forget --relationships` |
| 「情绪分数都删了」 | `companion.py forget --mood` |
| 「全部清空」 | `companion.py forget --all` |

这样执行只会列出会删掉什么，不动任何文件；你确认之后，它再加上 `--yes` 真正删除。

**不联网，只有一个例外，说清楚。** 八字、星盘、职业匹配都不联网，所以你的数据不会离开这台机器，也不产生任何 API 费用。**第一次**运行时脚本可能联网 `pip install` 那四个依赖：那是下载软件包，不是你的数据出去，但它确实是一次网络调用，所以写在这里。设 `LIFE_COMPANION_NO_AUTOINSTALL=1` 就能禁止它，脚本会改为打印安装命令。

**第一次对话就遇到危机，什么都不存。** 还没建档时，一个字都不留。已经在这里写日记的人，危机那条记录只会在明确告诉你的前提下记下，并告诉你怎么删。

## 遇到问题

**`doctor` 说缺依赖。** 脚本试过自动安装但没装上。`doctor` 会逐个列出安装命令和「少了它会怎样」：`pyswisseph` 只有西洋星盘要用，`sxtwl` 只用来交叉核验立春。碰到 PEP 668 那种 externally managed 的 Python，就装进虚拟环境，或者用 `pip install --user`、`pipx`、系统包管理器。

**这个 skill 出现了两次。** 你既装了插件，又在 `~/.claude/skills/` 里留了一份副本。系统不去重，删掉一份。

**`forget` 什么都没删。** 那是预览。它只列出会删掉什么，不动文件；照它给出的那条以 `--yes` 结尾的命令再跑一次。

**它不肯存我的生辰。** 生辰要先授权。没授权时 `set-profile` 会拒绝（退出码 3），什么都不写。不存也照样能在这次对话里把盘算出来。

**表单页面显示「打不开」。** 用服务打印出来的完整链接打开，就是末尾带 `?token=…` 的那条。只输 `http://127.0.0.1:8760/` 会被故意拒绝。

**表单服务起不来。** 多半是上次的表单服务还开着。它会自己往后找端口，连续十个都被占才会报错：跑一下 `pkill -f form_server.py`，或者直接在聊天里回答。

**在 Windows 上。** 用 `python`（或 `py -3`）代替 `python3`。那边的 `~/.companion` 没法用 `chmod 700` 锁住，所以「只有你能读」只在 macOS 和 Linux 上成立。

---

## 安全

可选的表单由临时 HTTP 服务提供，**只绑定 `127.0.0.1`**，提交后或者 15 分钟没人提交就自行关闭。页面会预先填好已经存的内容（包括生辰），提交会写进档案和同意记录，所以只绑定本机还不够。服务启动时会生成一次性 token 并写进打印的链接：页面只在带着这个 token、并且 Host 是服务绑定的地址时才打开，这也挡住了把恶意域名解析到 127.0.0.1 的网页。提交同样要带这个 token；浏览器带了 Origin 的话，还必须是这个页面自己的来源。一把锁保证只保存一次，除非启动时加了 `--keep-alive`。不符合的请求一律返回 403，什么都不写。

如实说明残余边界：**以你的身份**在**你的机器上**运行的任何进程，都能从终端里读到那个 token。所以它防的是恶意网页，不是已经以你账号运行的本机恶意程序。

`forget --all` 只会删除带有 `init` 写入的那份 README 的文件夹，所以 `COMPANION_HOME` 写错了也不会把无关的目录一起删掉。这个 skill 不用任何 API key，也不给医疗、财务、法律建议。
