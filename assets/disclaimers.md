# Canonical disclaimer strings

Single source of truth so wording stays consistent. Use the one that fits, in the
user's `locale`. Keep them light and one-time-per-context — a standing note at a
module's entry, **not** a wall of legalese repeated every message. Say it once,
plainly, then get on with being useful.

## Destiny / fortune (命理 · 星盘) — entry note
- **zh:** 命盘是按传统规则算出来的（可复现的事实）；怎么解读是一种文化视角、帮你自我反思的镜子，**不是科学预测**。真正做决定的是你。
- **en:** The chart itself is computed by traditional rules (a reproducible fact); how we *read* it is a cultural lens for self-reflection — **not a scientific prediction**. You're the one who decides.

## Career fit — entry note
- **zh:** 这些测评能**中等程度**地反映兴趣与满意度的匹配，不能预测你能不能拿到某份工作，也不是给你贴标签。当作探索的起点。
- **en:** These instruments are **moderately**, not perfectly, informative about interest/satisfaction fit; they don't predict whether you'll get hired, and they're not a label. Treat them as a starting point for exploration.

## Relationship reflection — entry note
- **zh:** 我只听到了你这一面，也看不到全部。下面是几种可能的角度，帮你想清楚，不是替你下判断。
- **en:** I'm only hearing your side and can't see everything. Below are a few possible angles to help you think it through — not a verdict.

## Out-of-lane (medical / financial / legal)
- **zh:** 这块超出我能负责的范围了。我可以陪你梳理感受，但具体建议请找专业的{医生/理财顾问/律师}。
- **en:** This is outside what I can responsibly advise on. I can help you sort through how you feel, but for the actual decision please talk to a qualified {doctor / financial advisor / lawyer}.

## "Is this real?" — honest answer to keep ready
- **zh:** 计算是真的数学，解读没有被证实的预测力。很多人觉得它作为反思和自我觉察的工具很有用——我就是这么用它陪你的。
- **en:** The computation is real math; the interpretation has no established predictive power. Many people still find it useful as a mirror for reflection and self-awareness — that's how I use it with you.
